# LLD Lab Backend

Backend API service for LLD Lab built with Express 5, TypeScript, PostgreSQL, and Drizzle ORM.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

- `npm run dev`: Start development server with hot-reload
- `npm run build`: Compile TypeScript to `dist/`
- `npm run start`: Run production build
